# Proposal: 首页时间显示组件

## Why

用户在使用小河日历时，需要一个直观的方式快速了解当前时间和日期相关信息。传统的日历应用通常只显示静态日期，用户需要额外查看系统时钟来获取时间信息。本功能通过在首页提供一站式的信息展示，解决以下问题：

1. **信息碎片化**: 用户需要在不同位置查看时间、日期、农历、节假日等信息
2. **时效性不足**: 静态日期显示无法满足实时查看的需求
3. **农历查询困难**: 传统日历应用对农历、节气、节假日支持不足
4. **调休提醒缺失**: 节假日调休补班信息难以直观获取

## Capabilities

### 核心功能

| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 实时时钟 | HH:MM:SS 格式显示，每秒自动刷新 | setInterval 定时器 |
| 日期显示 | YYYY年MM月DD日 格式 | computed 属性自动计算 |
| 星期显示 | 星期一 ~ 星期日 | 基于 Date.getDay() 映射 |
| 农历日期 | 显示农历月份/日期（如：正月初一） | tyme4ts 库计算 |
| 节气显示 | 当日若有节气则显示（如：立春） | tyme4ts 库计算 |
| 节假日标签 | 法定节假日突出显示（如：春节） | holidayData 数据查询 |
| 补休班提醒 | 调休上班日显示提醒（如：春节调休） | MAKEUP_DAYS 数据查询 |

### 技术特性

- **响应式设计**: 自适应屏幕宽度，移动端优化布局
- **深色模式**: 完整支持浅色/深色主题切换
- **性能优化**: 组件卸载时自动清理定时器，避免内存泄漏
- **类型安全**: 完整的 TypeScript 类型定义
