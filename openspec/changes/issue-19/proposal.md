# 提案：系统时钟区域唤醒精简日历窗口

## Why

此变更记录从 GitHub 迁移而来。

- **GitHub Issue**: #19
- **GitHub PR**: #20

**原始需求：**

在开启了hook系统时钟功能后，点击系统时钟区域时，唤醒一个新的精简的日历界面，而不是唤醒现有的程序主界面。

精简界面有以下的要求：
1. 点击系统时间区域唤醒要做到无延迟。不能点击后卡半天
2. 精简界面从上到下分三部分，分别是当前日期情况（时间，公历，农历，天气，节假日，节气），日期月份切换面板，日历面板（可以根据切换面板的操作进行日历切换），布局合理，界面美观
3. 日历面板显示公历，农历，节假日，节气，日程事件。点击日程事件唤醒主界面的日程事件详情
4. 节假日和工作日进行明显的颜色区分，要求颜色布局合理。
5. 鼠标点击日历面板可以日期选择，右键展开菜单：创建日程，查看日程，创建待办，查看当日截止的待办。这些功能项分别调整到主界面对应的功能区域。
6. 通过系统时钟区域唤醒唤醒的是精简界面和主界面无关。精简界面进行显隐。
7. 主界面的设置界面中需要有关于精简日历面板要有对应的设置项。可以控制面板的显示数据。
