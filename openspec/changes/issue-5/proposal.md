# 提案：关闭所有页面的默认右键菜单，并根据模块功能开启对应的右键菜单

## Why

此变更记录从 GitHub 迁移而来。

- **GitHub Issue**: #5
- **GitHub PR**: #13

**原始需求：**

- 关闭所有页面的默认右键菜单项，当前的右键菜单项是web的默认菜单项， 与程序功能不符，需要去掉。
- 对应的功能模块开启菜单项 
  - 【首页】【代办】代办项右键功能项：编辑、删除（需要二次确认）、完成、详情
  - 【首页】【日程】日程数据项右键功能：编辑、删除（需要二次确认）、完成、详情
  - 【代办】代办项右键功能项：编辑、删除（需要二次确认）、完成、详情
  - 【日程】日程数据项右键功能：编辑、删除（需要二次确认）、完成、详情
